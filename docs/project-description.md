\# Project Description



\## Overview



This project was created to demonstrate practical knowledge of Git and GitHub.



\## Objectives



The project demonstrates how to:



\- Initialize a Git repository

\- Track files using Git

\- Create meaningful commits

\- Create feature branches

\- Merge branches into the main branch

\- Use a `.gitignore` file

\- Connect a local repository to GitHub

\- Push source code to a remote repository



\## Application



The Python application contains a simple calculator with basic mathematical operations.



The project is mainly intended for practicing version control and GitHub workflow.
